What runs, and what does not

Implemented

  1. L2 logistic per category, with a standard scaler
  2. Isotonic calibration on the later half of each train window
  3. Expanding-window backtest, no shuffle, train always before test
  4. Brier, ECE with p=1 counted, ROC, log-loss

Not in this repo

  1. Live ingest. Staging files are empty JSON stubs
  2. Six of eight parsers
  3. An event store or market prices
  4. Any out-of-sample beat rate vs a book

Run it

git clone https://github.com/OliverKlug/Uncertainty-aware-political-prediction.git
cd Uncertainty-aware-political-prediction
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python src/pipeline/run_daily.py
python src/backtesting/run_backtest.py --category election --synthetic
pytest tests/ -v
